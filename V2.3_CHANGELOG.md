# RMRDC Research-to-Industry Intelligence Platform V2.3

## Investor Portal updates
- Replaced the illustrative Nigeria silhouette with a real interactive Leaflet/OpenStreetMap map.
- Added mapped sourcing points for Benue, Ogun, Oyo and Kaduna with availability levels and sourcing-intelligence popups.
- Added map legend, verification status, state brief action and supply-chain brief action.
- Added a Supply Intelligence & Evidence card with source/verification metadata.
- Converted “Need deeper intelligence?” into an operational due-diligence workflow.
- Added Request Full Brief / View-Book Briefing / Start Engagement actions.
- Added controlled-access intelligence request modal for technical, financial, IP, supply-chain, regulatory and researcher materials.
- Added engagement workflow modal for technical meeting, pilot/site visit, JV and licensing discussions.
- Added evidence-backed, controlled-access and RMRDC-traceable indicators.

## Platform-realisation direction
The investor portal is now designed as a decision and engagement layer over CAS/SDI. In production, replace the mock values with verified RMRDC records, document IDs, validation dates, supplier records, geospatial coordinates and access-control rules.
