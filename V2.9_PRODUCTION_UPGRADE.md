# RMRDC Research-to-Industry Intelligence Platform — V2.9 Production Upgrade

This release upgrades the existing V2.8 RMRDC platform rather than replacing it.

## Implemented

- Role-based registration for Researcher, Investor, Library User and Fabricator.
- Role-specific registration fields.
- Structured multi-select research/investment interests with an `Other` option.
- Supabase-backed platform profiles and user-interest relationships.
- Configurable matching weights and matching data model.
- Technology, raw-material, technology-match and CAS intelligence entities in the database schema.
- Investor portal personalization using the registered investor profile.
- Match scores and match-reason tooltips for technology opportunities.
- Landing-page Investor Information Needs remains exclusively on the public landing page.
- Removed production-undermining prototype/illustrative language from key platform messaging.
- Preserved the existing CAS, digital-library, raw-material and portal functionality.

## Deployment

Run the additional SQL in `supabase/setup.sql` against the existing Supabase project before enabling authenticated profile registration and matching.

The application remains compatible with the existing static HTML/CSS/JavaScript + Supabase architecture of V2.8.
