# RMRDC v3.4.9 — Clean Engagement & Researcher Investor Details

## Changes
- Removed the redundant “What happens next?” investor panel from the Investor Portal.
- Removed the secondary Request Researcher Engagement and Request Fabrication / Scale-up buttons from RMRDC asset detail cards; Express Interest is now the single primary engagement entry point.
- Kept the Expression of Interest form available for all technology/asset views through the shared EOI workflow.
- RMRDC assets now pass their asset context into the EOI workflow.
- Researcher Portal “Interested Investors” now displays investor name, organisation, email, phone, technology, interest type, preferred next step and approval status.
- Added a “View Interest” detail view and a controlled “Open Deal Room” action for approved interests.
- Deal Room remains gated by RMRDC approval and technology opportunity assignment.
